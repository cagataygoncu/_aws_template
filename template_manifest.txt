# template_manifest.txt - who owns each file of a generated project.
#
# Paths are as they appear in a generated project, not in _base/ or a layer.
# One rule per line: <class> <pattern>. The first matching rule wins, so the
# specific rules sit above the broad ones. `*` matches across `/`.
# `make check-manifest` renders every language and fails on any file no rule
# matches, so a new file cannot ship unclassified.
#
# Classes - what a template upgrade does with the file:
#
#   stamp     written by bootstrap, rewritten by every upgrade.
#   template  the template owns it. An upgrade merges the template's change
#             into it (3-way: old render, new render, project). Project edits
#             survive; an edit that clashes shows as a merge conflict.
#   seed      a starting point the project owns from then on. An upgrade
#             creates it if missing; otherwise it only reports the template's
#             change, for a person to port while keeping the project's values.

stamp     .template.env
